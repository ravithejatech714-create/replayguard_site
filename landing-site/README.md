# ReplayGuard

ReplayGuard is a self-hosted Kafka replay and debugging platform for engineering teams that need safer message inspection, controlled replay workflows, audit history, and operational visibility.

This repository contains the public website for ReplayGuard.

## What ReplayGuard Helps With

- Browse Kafka topics with bounded inspection controls.
- Validate replay requests before execution.
- Run controlled replay workflows with pause, resume, cancel, retry, and rerun controls.
- Track replay jobs, worker progress, and audit history.
- Support self-hosted deployment for teams that need Kafka access to stay inside their environment.

## Product Areas

- Kafka profile management
- Topic exploration and message browsing
- Replay job creation and validation
- Worker execution visibility
- Audit logs and operational dashboards
